# Date Box Design System

## 设计方向

关键词：梦幻、心动、奶油感、粉紫渐变、克制玻璃质感。整体要像一份被认真准备的小礼物，而不是婚礼请柬、霓虹夜店、爱心贴纸墙或后台仪表盘。

## 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| `background` | `#FFF8FC` | 页面奶油粉底色 |
| `background-secondary` | `#F8F0FF` | 淡紫辅助底色 |
| `surface-soft` | `rgba(255,255,255,.42)` | 最轻容器层 |
| `surface` | `rgba(255,255,255,.64)` | 默认玻璃容器 |
| `surface-strong` | `rgba(255,255,255,.86)` | 重点浮层，克制使用 |
| `pink-100` | `#FFE2EE` | 柔粉填充 |
| `pink-300` | `#FBA6C8` | 次级强调、描边 |
| `pink-500` | `#E95E9B` | 品牌强调 |
| `pink-600` | `#CF3F82` | 文字与主按钮深色端点 |
| `purple-200` | `#DDC5FF` | 淡紫填充 |
| `purple-400` | `#A984DF` | 轨迹与互补强调 |
| `purple-500` | `#8E67C7` | 主按钮深色端点 |
| `text-primary` | `#51394F` | 主文字 |
| `text-secondary` | `#80677C` | 次级文字 |
| `text-muted` | `#A78FA3` | 辅助文字 |

主渐变使用 `pink-600 → purple-500`，只用于关键按钮、进度或焦点视觉；较深端点保证白色按钮文字清晰。页面背景使用三层低对比径向渐变叠加奶油色线性渐变，不做满屏高饱和渐变。正文对比度目标至少 4.5:1，交互边界至少 3:1。

## 字体

- 界面默认：`PingFang SC`、`Microsoft YaHei`、`Noto Sans SC`、系统无衬线回退；不加载外部字体。
- 数字、阶段标签：系统等宽字体，可用于默契分数和步骤编号。
- 品牌标题：使用无衬线中等或半粗字重，通过字距和构图建立气质，不额外引入网络字体。
- 正文移动端 16px/1.65，辅助文字 13–14px/1.5，主标题使用 `clamp(2.5rem, 8vw, 5.5rem)`。
- 中文不使用过细字重，不使用手写体大段排版。

## 圆角

- 小控件与标签：12px 或胶囊形。
- 按钮与输入：16px。
- 普通卡片：24px。
- 核心场景卡片/盲盒：32px。
- 圆角层级随容器尺寸增大，不让所有元素都成为胶囊。

## 阴影与玻璃质感

- 普通卡片：`0 12px 40px rgba(92, 56, 80, .08)`。
- 浮起状态：`0 20px 60px rgba(92, 56, 80, .14)`。
- 玻璃卡片必须同时具备半透明暖白底、1px 白/粉边界和 12–24px 模糊；同屏最多两层玻璃。
- 不使用彩色外发光包围全部组件。

## 间距

采用 4px 基础网格：4、8、12、16、20、24、32、40、48、64、80、96。

- 控件内部：12–16px。
- 同组元素：8–12px。
- 卡片内部：移动端 20–24px，桌面端 28–36px。
- 页面段落：移动端 48–64px，桌面端 72–96px。

## 容器

- 全局最大宽度：1200px。
- 主要互动列：移动端全宽，桌面 560–680px。
- 计划详情：桌面可使用 720–880px。
- 页面安全边距：移动端 20px，768px 起 32px，1200px 起 48px。
- 长文本行宽控制在 36–68 个中文字符。

## 按钮

- 最小触控区域 44×44px，主按钮高度 52–56px。
- 主按钮：粉紫渐变、白字、16px 圆角；每个视图只设一个明确主动作。
- 次按钮：暖白半透明背景、粉色边界、深色文字。
- 文本按钮：用于返回或跳过，必须保留清晰 hover/focus 区别。
- 状态：hover 轻微上移 1px；pressed 缩放至 0.98；disabled 降低对比并取消阴影。
- 键盘焦点统一使用 2px `rose-500` 外环和 3px 偏移，不以移除 outline 作为美化。

## 卡片

- 选择卡片整块可点击，并提供图形、标题和一句说明；图形使用 Lucide，不用 emoji 充当 UI 图标。
- 选中状态至少通过边界、背景和勾选图标三个信号中的两个表达，不能只靠颜色。
- 路线卡片使用编号/时间、标题、描述、任务四层信息，时间线在移动端保持单列。
- 同组卡片高度尽量一致，但不能截断正文。

### 异步邀请与结果卡

- 邀请卡和结果卡固定为 `3 / 4`，移动端推荐宽度 330–340px；截图模式必须完整落在 375×812 的可视区域内。
- 两类卡片都保留 Date Box / 心动计划局品牌、奶油纸张底、单个异形圆角和克制的粉紫轨迹，不使用婚礼请柬装饰。
- 邀请卡可以包含完整邀请 URL 的高对比度 SVG 二维码，但卡片正文不显示完整长链接或玩家 A 选择。
- 结果卡只显示双方称呼、默契度、最多三个今日关键词、共同计划名和一句纪念文案，不展示五道完整答案。
- 结果卡分数是唯一的大号数据；关键词和日期保持辅助层级，避免做成统计仪表盘。
- 空称呼使用“有人”“TA”等中性回退；长称呼仍受 12 字符数据约束，卡片不得截断关键计划名。

## 动效

- 微反馈 140–220ms；页面切换 320–480ms；盲盒核心揭示最多 900ms。
- 默认 easing：`[0.22, 1, 0.36, 1]`；退出可用更快的 ease-in。
- 只动画 `transform` 与 `opacity` 为主，避免大面积模糊和布局抖动。
- 长按必须有连续进度、取消反馈和键盘等价操作。
- `prefers-reduced-motion` 下移除位移、视差与循环动效，仅保留快速淡入和即时状态变化。
- 同屏循环装饰不超过 3 个，不使用 Canvas 粒子系统。

## 响应式规则

- Mobile-first，核心验收尺寸为 390×844；同时保证 320px 宽度可用。
- 768px 起，选项可由单列变为两列，避免按钮过宽。
- 1024px 起启用设计过的桌面构图：内容居中或左右分栏，不简单放大移动版。
- 桌面验收尺寸为 1440×900，关键主动作无需滚动即可看到；长内容允许自然滚动。
- 使用动态视口单位 `dvh`，处理安全区域；任何断点均不得横向滚动。
- 异步结果详情在移动端按“双方称呼 → 默契结果 → 共同/互补 → 推荐计划 → 隐藏任务 → 操作”顺序单列；1024px 起使用结果卡与详情左右分栏。
- 截图模式隐藏品牌导航和卡外操作，只保留顶部截图提示、居中的 3:4 卡和底部退出区域。

## 禁止出现的视觉问题

- 婚礼请柬式花体、蕾丝、金色边框和大量鲜花。
- 廉价高饱和霓虹、整页紫蓝渐变和过量外发光。
- 大量爱心图标、emoji 作为图标、幼稚贴纸风。
- 后台模板式侧栏、统计卡片、表格和密集信息块。
- 玻璃层级过多导致文字低对比或背景脏乱。
- 选中、禁用、焦点和错误状态不可辨认。
- 装饰遮挡交互、文字截断、横向溢出、动效引发布局位移。
